# UGC Fashion Skill

A fashion UGC skill designed to generate human-like fashion affiliate content, image-reference prompts, and frame-to-frame video prompts.

## Core workflow

Product → Campaign → Creator → Content → Platform → Content Logic → Creative Concept → Script/Behavior → Storyboard → Image Prompts → Frame-to-Frame Video Prompts → Human Realism & Product Consistency QA

## User input

### 1. Product
- Product name
- Product URL

### 2. Campaign
- Campaign objective
- Campaign stage
- CTA

### 3. Creator
- Gender
- Age range
- Appearance
- Body type
- Style
- Creator reference

### 4. Content
- Content format
- Content angle
- Duration: 4s, 6s, 8s, 10s, or custom
- Scene count: Auto, 2, 3, 4, 5, or custom

### 5. Platform
- TikTok
- Instagram Reels
- Facebook Reels
- Shopee Video

## Design principles

1. Keep user input simple; creative complexity stays inside the skill.
2. Separate content format (how content is executed) from content angle (what the content communicates).
3. Talking formats use dialogue scripts; silent formats use behavioral scripts.
4. Image and video prompts are generated from storyboard decisions, not independently.
5. Preserve product identity and visual consistency across scenes.
6. Optimize for believable human UGC rather than overly polished commercial fashion imagery.
