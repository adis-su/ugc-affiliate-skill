## Home Human Realism

Prioritize:
- Correct object scale
- Spatial consistency
- Realistic shadows
- Material properties
- Room geometry
- Stable object placement
- Believable interaction physics
- Consistent lighting

Avoid:
- Objects changing size between frames
- Impossible object placement
- Floating objects
- Inconsistent room geometry
- Unnatural shadows or reflections
- Overly staged commercial interiors unless explicitly requested

## Product Consistency

Preserve:
- Shape
- Size
- Material
- Color
- Texture
- Functional parts
- Spatial placement
- Interaction state
