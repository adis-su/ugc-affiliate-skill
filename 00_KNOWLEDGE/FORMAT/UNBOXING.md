# AFFILIX — Unboxing Format

Unboxing adalah format konten yang berfokus pada pengalaman membuka, memperlihatkan, dan mengenalkan isi sebuah produk atau paket.

Format ini adalah **content knowledge**, bukan template wajib. Content Strategy tetap menentukan apakah Unboxing sesuai untuk project.

## 1. Core Structure

Struktur dasar:

**PACKAGE CONTEXT → OPENING → REVEAL → DETAIL → FIRST INTERACTION → IMPRESSION/USE → CTA**

Tidak semua bagian harus menjadi scene terpisah.

## 2. Package Context

Tujuan:
- memperkenalkan paket
- membangun curiosity
- menetapkan environment dan starting state

Visual dapat menunjukkan:
- package masih tertutup
- character menerima atau mengambil package
- package berada di meja atau lokasi yang relevan

Product Identity belum boleh berubah hanya karena packaging sedang dibuka.

## 3. Opening

Opening menunjukkan proses membuka package.

State transition harus jelas, misalnya:

**CLOSED PACKAGE → OPEN PACKAGE**

Aksi dapat mencakup:
- membuka box
- melepas seal
- membuka wrapping
- mengangkat lid

Jangan mengarang mekanisme packaging yang tidak diketahui.

## 4. Reveal

Reveal memperlihatkan product atau isi package.

Fokus visual:
- product identity
- packaging
- variant
- quantity
- included items jika memang terverifikasi

Reveal bukan alasan untuk menambahkan item yang tidak diketahui ada di package.

## 5. Detail

Detail shot dapat digunakan untuk memperlihatkan:
- logo
- label
- packaging details
- texture jika benar-benar dapat divisualisasikan dari source
- physical features
- printed information

Detail harus mengikuti Product Truth.

Jangan membuat tulisan pada packaging yang tidak tersedia.

## 6. First Interaction

Character mulai berinteraksi dengan product.

Contoh:
- mengambil product
- memutar packaging
- membuka product
- memeriksa bagian tertentu
- menyiapkan product untuk digunakan

Product State harus direpresentasikan secara eksplisit.

## 7. Impression / Use

Jika ada penggunaan produk, tampilkan hanya apa yang dapat didukung.

Unboxing dapat berakhir pada:
- first look
- first touch
- preparation
- initial use
- transition menuju format lain

Jangan membuat pengalaman pribadi palsu.

Jika dialogue menggunakan first-person statement, statement tersebut harus memiliki dasar dari konteks project atau ditulis sebagai fictional performance yang tidak diposisikan sebagai fakta pengguna nyata.

## 8. CTA

CTA dapat mengarahkan audience untuk:
- melihat detail produk
- mengecek variant
- mengecek harga
- melihat halaman produk
- mengikuti konten berikutnya jika memang sesuai strategy

CTA tidak boleh menjanjikan hasil yang tidak didukung.

## 9. Hook Patterns

Unboxing dapat menggunakan:
- curiosity tentang isi package
- anticipation sebelum reveal
- direct reveal setup
- packaging detail
- reason for opening

Hook tidak boleh memalsukan isi package.

Contoh struktur:

**"Gue baru buka paket ini dan ternyata..."**

Kalimat lanjutan harus tetap sesuai fakta yang tersedia.

## 10. Visual Pattern

Pola visual umum:

1. Package berada pada starting position.
2. Character masuk atau mulai berinteraksi.
3. Package dibuka.
4. Isi diperlihatkan.
5. Product diambil.
6. Product diperiksa atau digunakan.
7. Final state mengarah ke CTA.

Continuity harus mempertahankan:
- character
- outfit
- environment
- package
- product
- camera relationship
- lighting

## 11. Script Pattern

Script dapat menggunakan:

```text
HOOK
PACKAGE CONTEXT
OPENING
REVEAL
PRODUCT DETAIL
FIRST INTERACTION
OPTIONAL FIRST USE
CTA
```

Dialogue harus tetap conversational.

Jangan mengubah struktur script menjadi daftar spesifikasi yang terdengar seperti katalog.

## 12. Storyboard Pattern

Storyboard perlu menentukan:
- package position
- character position
- opening action
- reveal moment
- product state
- camera framing
- interaction
- final state

Setiap scene harus memiliki visual purpose yang jelas.

## 13. State Considerations

Unboxing sangat bergantung pada state transition.

Contoh:

**PACKAGE: CLOSED → OPEN**

**PRODUCT: HIDDEN → VISIBLE → HELD → OPEN/READY**

State harus berubah secara logis.

Jika package memiliki beberapa komponen, jumlah dan jenis komponen harus berasal dari Product Truth atau source yang relevan.

## 14. Reference Considerations

Reference image harus merepresentasikan state yang benar.

Contoh:

**R01**
- package closed
- product not visible

**R02**
- package open
- product visible

**R03**
- product held by character

Reference tidak boleh digunakan untuk memperkenalkan detail product yang belum ditetapkan.

## 15. Common Failure Modes

### Invented Contents
AI menambahkan item yang tidak ada dalam source.

### Packaging Drift
Bentuk, warna, logo, atau tulisan packaging berubah.

### Impossible Opening
Mekanisme membuka package tidak masuk akal.

### Product Teleportation
Product berpindah posisi tanpa transition.

### Identity Drift
Product atau character berubah saat camera angle berubah.

### Fake First Impression
Dialogue mengklaim pengalaman nyata yang belum memiliki dasar.

### Reveal Without State
Product tiba-tiba sudah terbuka atau berada di tangan tanpa transition.

## 16. Best Use Contexts

Unboxing cocok dipertimbangkan ketika:
- packaging merupakan bagian penting dari pengalaman produk
- reveal dapat memberikan curiosity
- product memiliki physical presence yang menarik
- first interaction relevan dengan audience

Unboxing kurang relevan jika packaging tidak memiliki peran dalam cerita dan produk lebih cocok langsung didemonstrasikan.

## 17. Transition to Other Formats

Unboxing dapat menjadi pembuka untuk:
- Review
- Demonstration
- Tutorial
- Problem-Solution
- Routine

Jika cerita berpindah format, Content Strategy harus menentukan transition tersebut.

## 18. Non-Negotiable Rules

1. Jangan mengarang isi package.
2. Jangan mengarang mekanisme packaging.
3. Jangan mengubah Product Identity.
4. Product State harus memiliki transition yang logis.
5. Jangan membuat testimonial atau first impression palsu.
6. Packaging text harus mengikuti source.
7. Reference harus merepresentasikan state yang benar.
8. Unboxing tidak otomatis berarti review.
9. Format tidak membuat keputusan strategy secara otomatis.
10. Semua downstream output harus tetap tunduk pada Product Truth.
