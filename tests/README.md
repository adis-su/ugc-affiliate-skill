# Validator Test Fixtures

Fixtures are intentionally small and human-readable. They represent representative valid and invalid states across the UGC pipeline.

## Fixture categories

- valid format executions
- format/behavior conflicts
- timing failures
- storyboard continuity failures
- product identity drift
- frame transition failures
- mirror geometry failures
- CTA mismatches
- creator continuity failures
- unsupported product claims

## Test principle

A fixture should verify a specific validator rule rather than test the entire creative system at once.
