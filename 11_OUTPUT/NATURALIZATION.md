# NATURALIZATION

## 1. Purpose

Naturalization is the controlled downstream layer that makes generated character, product, camera, and environmental behavior feel naturally human and physically plausible.

It does not create new narrative content. It refines motion and behavior already permitted by upstream specifications.

Core model:

`SPECIFIED STATE → CONTROLLED MICRO-MOTION → SAME REQUIRED STATE`

Naturalization must preserve:
- Source of Truth
- Character Identity
- Product Identity
- required Character State
- required Product State
- required Environment State
- required Camera State
- narrative meaning
- dialogue meaning
- continuity
- claim safety

Naturalization is an output refinement layer, not a new creative stage.

---

## 2. Boundaries

Naturalization receives constraints from:
- Character Identity
- Voice Identity
- Performance
- Environment
- Visual Language
- Clip
- Visual State
- Character State
- Product State
- Camera State
- Reference State
- Production Spec
- Image Spec
- Video Spec
- Audio Design

Naturalization informs:
- Image Prompt where still-image naturalness requires controlled detail
- Video Prompt through the Naturalization Block

Naturalization does not overwrite upstream modules.

### Naturalization is NOT

Naturalization is not:
- a replacement for Character Performance
- a replacement for Video Spec
- a replacement for Camera State
- a replacement for Visual Language
- an excuse to invent actions
- an excuse to change identity
- an excuse to alter required state
- an excuse to add unsupported product behavior
- a separate validation stage

---

## 3. Core Principle

Natural-looking does not mean random.

Every naturalization change must satisfy:
1. It is physically plausible.
2. It is compatible with the current state.
3. It does not alter identity.
4. It does not alter the required end state.
5. It does not create a new narrative beat.
6. It does not contradict the reference.
7. It does not introduce unsupported claims or product properties.

When there is a conflict, upstream Source of Truth wins.

---

## 4. Naturalization Record

A Naturalization Record may contain:

| Field | Description |
|---|---|
| Naturalization ID | Unique record ID |
| Scene ID | Related scene |
| Clip ID | Related clip |
| Reference ID | Relevant start/end/bridge reference |
| Source State | State being naturalized |
| Target State | Required resulting state |
| Character Micro-Motion | Allowed character micro-movements |
| Facial Micro-Motion | Blink, gaze, subtle facial movement |
| Hand Micro-Motion | Finger and grip adjustments |
| Body Micro-Motion | Breathing, posture settling, weight shift |
| Product Micro-Motion | Physically plausible handling adjustments |
| Camera Micro-Motion | Handheld drift, focus behavior, stabilization |
| Environment Micro-Motion | Subtle environmental movement |
| Speech Naturalness | Speech-related movement and timing |
| Timing Constraints | When naturalization may occur |
| Prohibited Changes | Changes that must not occur |
| Intensity | Degree of naturalization |
| Continuity Anchors | Elements that must remain stable |
| Audio Dependencies | Relevant audio synchronization |
| Source References | Upstream sources |
| Status | Current record state |

---

## 5. Identity Protection

Naturalization must never modify identity.

### Character Identity

Naturalization must preserve:
- face shape
- facial proportions
- eye structure
- eyebrow structure
- nose structure
- lip proportions
- skin characteristics
- visual age
- body identity
- wardrobe identity
- permanent hijab requirement
- complete hair coverage

For Rositasari, hijab presence and full hair coverage remain protected during head movement, camera movement, close-ups, side angles, hand interaction, walking or body movement, transitions, and generated motion artifacts.

Naturalization may make movement around the hijab look natural, but may not reveal hair or redefine the character.

### Product Identity

Naturalization must preserve:
- brand
- product name
- variant
- shape
- color
- packaging
- material appearance
- logo
- printed details
- physical design

A product handling adjustment must never become a product redesign.

---

## 6. State Protection

Naturalization may add motion inside an allowed state, but may not silently create a different state.

### Allowed

- fingers slightly reposition while still holding the product
- subtle breathing while standing
- a blink while looking at the product
- tiny gaze correction while maintaining the required gaze target
- minor handheld camera drift while maintaining framing
- autofocus settling while maintaining the same subject

### Not Allowed

- closed product becoming open
- held product becoming placed
- product moving to another hand when that changes continuity
- character sitting when the required state is standing
- gaze shifting to an unrelated subject
- camera moving to materially different framing
- wardrobe or hijab changing
- product label changing
- new object appearing

The required state always wins over naturalization.

---

## 7. Character Micro-Motion

Natural character movement can include:
- subtle breathing
- slight chest or shoulder movement
- natural blinking
- small eye adjustments
- tiny head stabilization movements
- subtle posture settling
- minor weight redistribution
- natural hand relaxation
- small finger repositioning
- subtle wrist adjustment
- realistic movement caused by speech
- small facial muscle changes consistent with the required expression

Micro-motion remains subordinate to the primary performance.

Naturalization must not turn a stable pose into a new action.

---

## 8. Facial and Eye Naturalization

Facial naturalization may include:
- natural blink timing
- slight eyelid movement
- tiny gaze correction
- subtle eyebrow movement
- small mouth movement during speech
- realistic facial settling
- slight expression fluctuation around the required expression

Naturalization must preserve the specified expression and emotional direction.

A neutral expression may contain life and movement without becoming a smile.

A smile may contain subtle variation without becoming a different emotional beat.

Facial movement must never change facial identity.

---

## 9. Breathing and Body Naturalization

Breathing may be represented through:
- subtle chest movement
- slight shoulder movement
- tiny posture changes
- natural pause and recovery during speech

Body naturalization may include:
- small weight shifts
- minor balance corrections
- natural posture settling
- slight shoulder relaxation
- subtle arm repositioning

These changes must remain compatible with:
- body position
- pose
- posture
- spatial position
- product interaction
- camera framing

---

## 10. Hand and Finger Naturalization

Hands are a high-risk continuity area.

Allowed:
- subtle finger flex
- minor grip adjustment
- natural thumb repositioning
- small wrist correction
- slight relaxation of unused fingers

Required relationships must remain unchanged.

Example:

`RIGHT HAND HOLDS PRODUCT → MICRO-ADJUSTMENT → RIGHT HAND STILL HOLDS PRODUCT`

Naturalization must not:
- swap hands without instruction
- release the product
- create extra fingers
- remove fingers
- change grip into a different interaction
- move the product to an unsupported location

---

## 11. Product Handling Naturalization

Product handling may contain small physical adjustments when compatible with Product State.

Examples:
- slight grip adjustment
- small finger pressure changes
- subtle wrist movement
- minor repositioning inside the same interaction
- natural settling after pickup or placement

Naturalization must not change:
- open/closed state
- quantity
- orientation when orientation is a continuity anchor
- visibility requirements
- contents visibility
- product identity
- interaction state

No product feature, mechanism, material, or performance may be invented through naturalization.

---

## 12. Speech-Related Naturalization

Speech should not look mechanically synchronized.

Naturalization may include:
- subtle mouth movement
- natural blinking during speech
- small gaze changes
- breathing between phrases
- micro-pauses
- slight head movement
- tiny hand gestures already compatible with Performance
- natural emphasis-related facial movement

Dialogue meaning must remain unchanged.

Naturalization must not add:
- new spoken content
- new claims
- altered wording
- changed emotional meaning
- exaggerated gestures that create a new narrative beat

Voice Identity remains authoritative for vocal characteristics.

Audio Design remains authoritative for audio timing and sound layers.

---

## 13. Camera Naturalization

Camera naturalization may include:
- subtle handheld drift
- minor stabilization correction
- gentle autofocus behavior
- tiny focus settling
- small exposure adaptation
- realistic smartphone camera response

Camera naturalization must preserve required:
- camera position
- shot size
- framing
- subject relationship
- focus target
- spatial geometry
- continuity anchors

Camera movement must not become cinematic movement unless explicitly specified upstream.

Natural UGC camera behavior should feel incidental rather than artificially shaky.

---

## 14. Environment Naturalization

Environmental naturalization may include:
- subtle curtain movement
- minor light fluctuation when physically plausible
- small background movement
- natural atmospheric motion
- slight environmental object movement caused by existing physical interaction

It must not:
- relocate objects
- create new objects
- remove important objects
- change environment identity
- alter spatial layout
- introduce unexplained weather or lighting changes
- compete with the primary action

Environmental movement is secondary to the subject.

---

## 15. Timing Constraints

Naturalization must respect Global Timeline and Clip timing.

Micro-motion should occur only where it can exist without disrupting:
- dialogue
- action timing
- state transition
- camera transition
- product interaction
- scene pacing

Naturalization cannot extend or compress the required narrative event.

For a clip:

`START STATE → PRIMARY TRANSITION → END STATE`

Naturalization may occur around the transition, but the transition remains the dominant event.

---

## 16. Start and End State Stability

The beginning and ending states of a clip are continuity anchors.

At clip start:
- required Start State must remain recognizable
- unnecessary motion must not obscure important reference details

At clip end:
- required End State must settle clearly
- micro-motion must not prevent a stable bridge state
- continuity-critical product, character, environment, and camera details must remain readable

When Clip N ends and Clip N+1 begins:

`END STATE_N = START STATE_{N+1}`

Naturalization must not break this relationship.

---

## 17. Reference Integrity

Reference images represent declared Reference State.

Naturalization may improve perceived realism around the reference state, but may not redefine it.

The generated image or video does not become a new Source of Truth merely because it looks more natural.

If a generated result contains a useful accidental variation, that variation remains non-authoritative unless explicitly promoted upstream.

---

## 18. Naturalization Intensity

Naturalization should be controlled rather than maximized.

### Subtle

Use for:
- stable talking-head shots
- product close-ups
- reference-sensitive frames
- continuity-critical moments

Typical behavior:
- blinking
- breathing
- tiny gaze correction
- slight hand movement
- restrained camera response

### Moderate

Use when the scene naturally contains:
- conversational gestures
- product handling
- posture changes
- more visible camera response

Moderate naturalization still preserves the required state and primary action.

### Excessive Naturalization

Avoid:
- constant body movement
- random head turns
- exaggerated blinking
- unnecessary camera shake
- dramatic autofocus hunting
- uncontrolled hand movement
- decorative environmental motion

More motion does not automatically mean more realism. Humanity, tragically, is not measured in pixels per second.

---

## 19. Natural UGC vs Artificial Imperfection

UGC authenticity should come from believable behavior, not a checklist of defects.

Do not force:
- random camera shake
- fake blur
- excessive noise
- artificial focus errors
- exaggerated skin texture
- random framing mistakes
- unnecessary stumbles
- constant blinking
- meaningless object movement

Naturalization should reproduce plausible behavior, not manufacture incompetence.

---

## 20. Audio Relationship

Naturalization may depend on audio timing, but Audio Design remains authoritative for audio.

Visual naturalization may synchronize with:
- speech onset
- pauses
- emphasis
- breathing
- product sounds
- environmental sounds

Naturalization must not invent audio content.

Audio does not authorize a visual state change unless that change is already specified upstream.

---

## 21. Claim Safety

Naturalization must never introduce a product claim.

It cannot imply unsupported:
- performance
- durability
- material quality
- effectiveness
- health outcome
- technical capability
- size
- quantity
- user experience

If visual behavior could be interpreted as a product claim, upstream Product Truth and Claim Rules take priority.

---

## 22. Missing Data Handling

Do not invent missing naturalization constraints when the missing information could affect continuity or identity.

Use:
- UNKNOWN
- NEEDS INPUT
- BLOCKED

when necessary.

Non-critical micro-motion may remain unspecified and be generated conservatively.

Critical missing data must block downstream execution when it could materially change the required state.

---

## 23. Prohibited Naturalization

Naturalization must never:
- change Character Identity
- change Product Identity
- reveal protected hair
- alter wardrobe identity
- alter required pose
- alter required expression beyond permitted micro-variation
- change product open/closed state
- change product quantity
- change required product orientation
- swap hands without instruction
- change spatial relationships
- relocate environment objects
- change camera framing materially
- create a new narrative action
- create a new dialogue or claim
- change dialogue meaning
- alter voice identity
- introduce unsupported product behavior
- break clip bridge continuity
- promote generated artifacts into Source of Truth

---

## 24. Dependency and Stale Propagation

Naturalization depends on upstream state and production constraints.

Changes to:
- Character Identity
- Character State
- Product Identity
- Product State
- Environment
- Camera State
- Storyboard
- Timeline
- Clip
- Production Spec
- Video Spec

may make a Naturalization Record stale.

Stale naturalization must be revised before affected downstream prompts are treated as current.

Naturalization changes should not automatically invalidate unrelated modules.

---

## 25. Targeted Regeneration

When naturalization causes a problem, regenerate only the affected output.

Examples:
- unnatural blinking → adjust facial naturalization
- excessive camera shake → adjust camera naturalization
- awkward grip → adjust hand naturalization
- unstable end state → reduce motion near clip end
- environmental distraction → reduce environmental naturalization

Do not regenerate the entire project unless an upstream Source of Truth changed.

---

## 26. Status

Naturalization follows the project state model:

`NOT_STARTED → IN_PROGRESS → READY_FOR_DECISION → APPROVED → LOCKED`

If an upstream dependency changes:

`LOCKED → STALE → REVISED → LOCKED`

A generated output never automatically changes the Naturalization Record.

---

## 27. Boundary Summary

| Module | Owns | Does Not Own |
|---|---|---|
| Performance | Character behavior/performance | Micro-realism implementation |
| Visual Language | Visual presentation style | Required motion |
| Character State | Character condition | Naturalness layer |
| Product State | Product condition | Handling realism layer |
| Camera State | Camera condition | Incidental camera behavior |
| Video Spec | Required transition | Final micro-motion wording |
| Video Prompt | Generation instruction | Source of Truth |
| Audio Design | Audio behavior | Visual identity/state |
| Naturalization | Controlled human/physical micro-motion | Narrative or identity decisions |

---

## 28. Non-Negotiable Rules

1. Naturalization never overrides Source of Truth.
2. Naturalization never changes identity.
3. Naturalization never changes required state.
4. Naturalization never creates a new narrative action.
5. Naturalization never creates unsupported product claims.
6. Naturalization must preserve reference continuity.
7. Naturalization must preserve Start State and End State.
8. Naturalization must remain subordinate to the primary transition.
9. Natural UGC behavior must be plausible, not randomly defective.
10. Generated outputs never become Source of Truth automatically.
11. Naturalization is a controlled output layer, not a validation stage.
